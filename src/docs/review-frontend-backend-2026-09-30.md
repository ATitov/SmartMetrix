## Найдено и исправлено

| Приоритет | Проблема | Исправление |
|---|---|---|
| Высокий | Конвейер мог потерять признак тестового происхождения RTSP при настоящей сегментации | MeasurementDataProvenance разрешает производственное происхождение только для Arena и явного isTestData=false от обоих источников; неизвестное происхождение считается тестовым |
| Высокий | API геолога разрешал утвердить синтетический результат | Approved возвращает 409 TestResultCannotBeApproved для тестового или неизвестного происхождения |
| Высокий | Локальный launcher выбирал Simulator без явного запроса | Arena и StoneVision по умолчанию; Simulator/Deterministic и деморежим только через -TestMode |
| Средний | Интерфейс мог сообщать о доступности при частично неготовом контуре | Баннер и доступность команд зависят от фактического состояния; непроверенная готовность обозначена явно |
| Средний | После ошибки опроса старые сведения выглядели актуальными | Показывается потеря актуальности, запуск блокируется |
| Средний | Не было заметного предупреждения о тестовом результате, включая результат без D50 | Добавлены обозначения тестовых данных и неизвестного происхождения |
| Средний | Отсутствие activeMeasurementId в scoped API трактовалось как отсутствие активного измерения | Показывается «Не предоставлено API» |

Основные изменения: `WorkstationEndpoints.cs`, `ProcessingPipeline.cs`,
`MeasurementDataProvenance.cs`, `wwwroot/assets/smartmetrix.js`, `deploy/local/start.ps1`.

## Оставшиеся ограничения

1. **Высокий:** `src/docs/gui-prototype/app.js` содержит статические показатели, таблицы и
   графики. Прототип на порту 4180 не является рабочим интерфейсом. В ApiGateway
   реализованы самостоятельные страницы оператора и инженера. Для геолога, маркшейдера
   и администратора полные отдельные АРМ ещё требуется связать с API; административные
   функции частично встроены в инженерную панель.
2. **Высокий:** реальный полный цикл захвата и обработки не подтверждён. Камера Arena,
   StoneVision и Orchestrator возвращают неготовность. RigId, калибровка и привязка к
   оборудованию требуют реальных исходных данных. Область UNCONFIGURED обозначает
   отсутствие настройки, а не существующий участок.
3. **Средний:** scoped status не возвращает активное измерение и сообщает
   `canStart=null`, `triggerConditionsChecked=false`. Общая готовность сервисов не
   означает проверку физических условий съёмки. Интерфейс показывает этот предел.
4. **Средний:** 27 PostgreSQL-тестов пропущены. PostgreSQL-вариант хранения этим
   прогоном не проверен; текущий запуск использует локальный профиль.
5. **Средний:** базовый appsettings сегментации сохраняет Deterministic для локальных
   сценариев разработки. Проверенные launchers переопределяют его на StoneVision;
   отдельный запуск через dotnet run необходимо конфигурировать явно. Профиль
   SmartMetrix:DeploymentProfile=Production запрещает тестовый backend.

Это целевое ревью происхождения данных, интеграции и поведения GUI, а не подтверждение
промышленной приёмки, безопасности всего решения или точности измерительной модели.
