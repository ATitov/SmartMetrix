# Веб-интерфейс работы экскаватора

Экран `/excavation/` читает сохранённые сменные отчёты из ExcavatorReplay.
Доступны выбор области и смены, показатели циклов и покрытия, лента фаз,
фильтр статусов, подробности цикла и CSV. Интерфейс адаптирован для телефона.
Время показано со смещением смены, независимо от часового пояса браузера.

## Локальное демо

Из корня репозитория в PowerShell 7:

```powershell
./deploy/local/start-excavation-web.ps1
```

Скрипт собирает проект, воспроизводит синтетический набор и запускает отдельный
ApiGateway на `http://127.0.0.1:5191/excavation/`. Основной стенд на 5190 сохраняется.
Порт можно изменить параметром `-Port`; после сборки доступен `-NoBuild`.
Логин оператора и сгенерированный пароль находятся в
`artifacts/excavation-web/credentials.local.json`. Файл, хранилище пользователей,
ключи и журналы остаются в игнорируемом каталоге artifacts.

Остановка именно этого процесса:

```powershell
./deploy/local/stop-excavation-web.ps1
```

## Подключение сохранённых отчётов

В конфигурации ApiGateway для каждой существующей области задаётся каталог:

```json
{
  "ExcavationReports": {
    "Roots": {
      "demo-excavator": "C:/Users/Andrey/Documents/SmartMetrix/artifacts/excavator-replay"
    }
  }
}
```

Ключ — WorkstationScope.Id. Относительные пути считаются от ContentRoot ApiGateway.
Пользователь должен иметь доступ к области; отчёт должен содержать её ExcavatorId.
Без настройки экран показывает отсутствие отчётов. Повреждённые отчёты исключаются
из списка с предупреждением; JSON и CSV такого отчёта возвращают 409.
SHA-256 сменного JSON сверяется с манифестом перед выдачей.

API использует существующую авторизацию и ограничения области:

- `GET /api/v1/scopes/{scopeId}/excavation/runs` — список прогонов;
- `GET /api/v1/scopes/{scopeId}/excavation/runs/{runId}/report` — отчёт и источник;
- `GET /api/v1/scopes/{scopeId}/excavation/runs/{runId}/csv` — итог смены.

Пути сервера клиенту не выдаются. Каталоги с неверным идентификатором или
ссылками файловой системы не читаются; число каталогов и размер отчёта ограничены.

## Проверки

```powershell
dotnet test SmartMetrix.sln --configuration Release
cd tools/gui-tests
npm test
```

Браузерные проверки требуют Playwright и Chrome/Chromium. При необходимости
задайте `SMARTMETRIX_PLAYWRIGHT` (путь модуля) и `SMARTMETRIX_BROWSER` (исполняемый файл).
После запуска демо `node excavation-live.test.cjs` проверяет реальный вход,
отчёт, детали и CSV, сохраняет снимки в `artifacts/gui/`.

## Ограничения

Это просмотр сохранённых отчётов; кнопка «Обновить» перечитывает их.
Live-телеметрия, редактирование фаз, карта породы и управление машиной не подключены.
Синтетические данные отмечены явно. Масса, т/ч и л/т остаются неизвестными,
пока нет данных взвешивания и расхода топлива.
