# RTK Base — прототип управления UM982

Отдельное локальное приложение, не включённое в решение SmartMetrix. Node.js 22+; внешних пакетов нет. Работает на Windows и Linux, включая Raspberry Pi OS с подходящей версией Node.js.

## Запуск на компьютере

```powershell
cd tools/rtk-base-station
node server.mjs
```

Открыть http://127.0.0.1:8092. Остановка — Ctrl+C. Тесты: `node --test`.

## Что работает

- Серверное состояние базы и обновление панели раз в секунду.
- Ручные координаты, демонстрационное усреднение 15/60/300 секунд, отдельное подтверждение.
- Перенос блокирует выдачу и удаляет прежние активные координаты, включая после перезапуска.
- Профили мест, конфигурация mountpoint/порта, журнал последних 200 событий, выгрузка резервной копии.
- Симуляция отключения USB и спутниковых данных; остановка выдачи и отмена незавершённого усреднения.
- Адаптивный интерфейс на русском; управление с телефона.

## Границы прототипа

**Это симулятор, не готовая GNSS-база.** Он не открывает последовательный порт, не отправляет команды UM982, не генерирует RTCM и не открывает NTRIP-порт. Число спутников, скорость потока и ровер вымышлены. Настройки NTRIP сохраняются, но пока не управляют caster. Координаты усреднения заранее заданы. Резервную копию можно скачать; импорт не реализован.

После перезапуска координаты и профили сохраняются, но выдачу нужно включить вручную. Автоматический безопасный запуск реальной станции потребует проверки адаптера приёмника и состояния оборудования.

Данные хранятся в `data/station.json` (не включаются в Git). Другой файл можно задать через `RTK_DATA`. Порт веб-панели: `PORT`, по умолчанию 8092. Запускайте только один процесс с одним файлом данных.

## Доступ по локальной сети

По умолчанию панель слушает только loopback. Для LAN обязательна переменная `RTK_PASSWORD`; пользователь — `admin`. Пример для Linux, пароль вводится скрыто:

```bash
read -rsp 'Пароль панели: ' RTK_PASSWORD; echo
export RTK_PASSWORD
RTK_HOST=0.0.0.0 node server.mjs
```

Открыть `http://<IP Raspberry Pi>:8092`. HTTP Basic без TLS подходит только для изолированной доверенной тестовой сети. Для эксплуатации нужен HTTPS-прокси или VPN. Не публикуйте панель напрямую в интернет. Пароль панели не является паролем NTRIP.

## Проверка сценария

1. Открыть «Место установки», запустить усреднение на 15 секунд.
2. Дождаться результата, поставить отметку проверки и подтвердить.
3. Запустить выдачу; обзор показывает моделируемый поток и одного демонстрационного ровера.
4. Сохранить место. Отключить USB кнопкой в обзоре: выдача остановится.
5. Восстановить USB, вручную запустить выдачу.
6. Нажать «Перенести базу»: выдача прекращается; старое положение больше не доступно для запуска.
7. Выбрать сохранённое место или задать новые координаты, подтвердить и запустить.

## Следующий этап с оборудованием

1. Уточнить плату, прошивку UM982, USB serial ID и скорость порта; использовать стабильный `/dev/serial/by-id/...`.
2. Реализовать адаптер последовательного порта с проверкой ответов приёмника, реальными наблюдениями и обнаружением устаревшего потока.
3. Проверить формат координат/эллипсоидальной высоты и привязку антенны по документации конкретной прошивки.
4. Подключить реальный caster, источник RTCM и NTRIP-клиент на Raspberry Pi ровера. Проверить авторизацию и повторное подключение.
5. Добавить systemd-службы, запуск от отдельного пользователя, HTTPS/VPN, проверку восстановления после питания и watchdog.
6. На ровере проверить RTK FIX, возраст поправок и работу двухантенного курса. Определить точные координаты постоянной базы.
