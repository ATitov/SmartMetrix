# Браузерные проверки SmartMetrix

Обновлено 04.10.2026. `pnpm test` запускает три набора: `gui.test.cjs`
(макеты пяти АРМ), `workstation.test.cjs` (подключённые панели оператора/инженера)
и `excavation.test.cjs` (сменный отчёт экскаватора). Ответы API в браузерных
сценариях подставляются fixtures; серверный доступ проверяется отдельно в .NET-тестах.

Макеты: `src/docs/gui-prototype/index.html`. Открываются напрямую в браузере или через любой локальный статический сервер. Никаких учётных данных, внешних шрифтов, API или production-команд не используют.

## Запуск

Из этой папки:

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm test
```

Используется pnpm 11.19.0 и зафиксированный `pnpm-lock.yaml`. На Linux CI: `pnpm exec playwright install --with-deps chromium`.
Можно использовать имеющийся runtime: `SMARTMETRIX_PLAYWRIGHT` задаёт путь к модулю playwright, `SMARTMETRIX_BROWSER` — путь к исполняемому Chromium/Edge. Без переменных используется локальная зависимость и браузер Playwright.

Тест сам запускает статический HTTP-сервер на свободном loopback-порту и закрывает его после выполнения. Скриншоты пяти АРМ на пяти ширинах сохраняются в `artifacts/gui/`. Это артефакты проверки, не эталонный pixel-diff: оценка композиции требует просмотра снимков.
Браузерные fixtures получают точные байты файлов через Playwright route.fulfill: это исключает изменение тестируемого HTML локальными HTTP-инструментами. Проверки внешних запросов не отключены. В первоначальном локальном прогоне обнаружена инъекция скрипта антивируса в HTTP-ответ; настройки антивируса не менялись.

Для просмотра: `node tools/gui-tests/preview.cjs` из корня репозитория, затем `http://127.0.0.1:4180`. Сервер слушает только локальный компьютер. Макеты адаптивны, но для просмотра с отдельного телефона нужен отдельный согласованный сетевой способ публикации.

Покрытие: 42 теста — 25 комбинаций АРМ/ширины; пять наборов состояний; пять сценариев команд; пять touch-сценариев с увеличением базового шрифта до 32px; поиск, карточка и подтверждение версии; базовый контраст. Проверяются ошибки JS, отсутствие внешних запросов, горизонтального переполнения и слишком маленьких видимых основных controls. Диалоги проверяются с Escape, возвратом фокуса, валидацией и безопасным отображением комментария. Увеличение базового шрифта не заменяет ручную проверку browser zoom и всех подписей с фиксированным размером.

Браузерные fixtures не проверяют серверное применение RBAC и CSRF, реальные камеры,
3D, экранный диктор или аппаратные мобильные браузеры. Условия приёмки перечислены
в `src/docs/gui-requirements.md`. Макеты геолога, маркшейдера и администратора пока
не подключены к API; панели оператора/инженера и экран экскаватора проверяются отдельно.

`excavation.test.cjs` добавляет шесть проверок сохранённых смен: синтетический режим,
часовой пояс, фильтр и детали циклов, CSV, смена области, пустые/повреждённые отчёты
и мобильная ширина 390px. Общий `pnpm test` включает 54 проверки.
После запуска `deploy/local/start-excavation-web.ps1` можно отдельно выполнить
`node tools/gui-tests/excavation-live.test.cjs` из корня: реальный вход, отчёт,
детали, CSV и снимки `artifacts/gui/excavation-live-*.png`.
